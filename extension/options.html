yoink

Saves elements from web pages as code inspiration.

Each catch becomes a folder of its own inside this folder, with a README.md and the files next to it. The folder works as an Obsidian vault or inside one, but any folder will do. You can change it at any time; earlier catches stay where they are.

How to use: press ⌥⇧Y (Option-Shift-Y) or click the yoink icon, point at an element and click. Drag to catch an area. ↑/↓ move one level up or down, E turns extras on, Esc quits.
